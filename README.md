# Lovely Dust

Website: https://www.lovelydust.com

## Staging scope

This branch mirrors only the Divi child theme's code files (`theme/style.css`, `theme/functions.php`). It does not include Divi Builder page content, the Divi Theme Builder (global header/footer), menus, or any other content that lives in the WordPress database — that's only editable directly on the live site.
